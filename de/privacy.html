Datenschutzerklärung

Wie diese Website mit Informationen über ihre Besucher umgeht.

Zuletzt aktualisiert:

Wer betreibt diese Website?

Diese Website (andrejkirbis.com) ist eine persönliche akademische Website von Andrej Kirbiš, ordentlicher Professor an der Universität Maribor, Philosophische Fakultät, Institut für Soziologie, Slowenien. Es handelt sich um eine statische Website auf GitHub Pages ohne serverseitige Datenbank oder Benutzerkonten.

Welche Daten werden erhoben?

Diese Website verwendet standardmäßig keine Analysedienste. Wenn Sie auf Nachfrage Analyse-Cookies akzeptieren, wird Google Analytics 4 geladen und erhebt die unten beschriebenen aggregierten statistischen Daten. Bei Ablehnung oder Nichtbeachtung werden keine Analysedaten erhoben oder gesendet.

GitHub Pages (betrieben von GitHub, Inc.) kann im Rahmen des regulären Hostings grundlegende Serverprotokolldaten erheben (IP-Adressen, Browserkennung, Verweisquelle und Zeitstempel). Einzelheiten finden Sie in der Datenschutzerklärung von GitHub .

Google Analytics 4 (optional, einwilligungsbasiert)

Wenn Sie Analyse-Cookies akzeptieren, lädt diese Website Google Analytics 4 (Mess-ID: G-GXLELRGY99). GA4 kann anschließend folgende Daten erheben:

  • Seitenaufrufe und Navigationspfade auf dieser Website
  • Ungefähres Land oder Region (kein genauer Standort)
  • Gerätetyp, Browser und Betriebssystem
  • Verweisquelle, über die Sie auf diese Website gelangt sind

Google verarbeitet diese Daten gemäß seiner Datenschutzerklärung. Die Daten dienen ausschließlich dazu, die Nutzung der Website zu verstehen und ihre Inhalte zu verbessern. Sie werden für Werbung oder Remarketing nicht verwendet. Sämtliche werbebezogenen Einwilligungssignale bleiben unabhängig von Ihrer Analyseentscheidung dauerhaft abgelehnt.

Links zu Drittanbietern

Diese Website verlinkt auf ORCID, Google Scholar, Scopus, Web of Science, ResearchGate, SICRIS, SciProfiles und die Universität Maribor. Bei Zustimmung zu Analyse-Cookies werden zudem Daten an Google (Google Analytics 4) gesendet. Es gelten die Datenschutzbestimmungen der jeweiligen Dienste. Diese Website hat keinen Einfluss auf deren Inhalte oder Datenschutzpraktiken und übernimmt dafür keine Verantwortung.

Cookie-Einstellungen und Einwilligung

Bei Ihrem ersten Besuch fragt ein Banner nach Ihrer Einwilligung in Analyse-Cookies. Ihre Entscheidung wird im lokalen Browserspeicher unter folgendem Schlüssel gespeichert: ak_analytics_consent. Sie können Ihre Einwilligung jederzeit ändern oder widerrufen, indem Sie auf Cookie-Einstellungen in der Fußzeile einer beliebigen Seite klicken.

Nach dem Widerruf wird Google Analytics bei künftigen Besuchen nicht mehr geladen. Bereits während früherer Sitzungen mit Einwilligung erhobene Daten bleiben davon unberührt.

Google Fonts

Diese Website lädt Schriftarten von Google Fonts über HTML-Linkelemente. Beim Laden des Stylesheets wird eine Anfrage an Google-Server gesendet, die Ihre IP-Adresse gemäß der Datenschutzerklärung protokollieren können. Sie können diese Anfragen mit einer Browsererweiterung oder einem datenschutzorientierten Browser blockieren.

Kontakt per E-Mail

Wenn Sie eine E-Mail an die auf der Kontaktseite angegebene Adresse senden, werden Ihre E-Mail-Adresse und der Nachrichteninhalt ausschließlich zur Beantwortung Ihrer Anfrage verwendet. E-Mails werden nicht an Dritte weitergegeben und gelöscht, sobald sie nicht mehr benötigt werden.

Ihre Rechte (DSGVO)

Wenn Sie Analyse-Cookies akzeptiert haben, kann Google Analytics aggregierte Besuchsdaten speichern. Sie können Google Analytics über das Browser-Add-on zur Deaktivierung von Google Analytics deaktivieren oder Ihre Einwilligung jederzeit über den Link Cookie-Einstellungen in der Fußzeile widerrufen.

Bei Daten, die der Hostinganbieter GitHub speichert, wenden Sie sich bitte direkt an GitHub. Weitere Datenschutzanfragen richten Sie an: andrej.kirbis@um.si.

Änderungen dieser Erklärung
