Política de Privacidad

Cómo este sitio web maneja la información sobre sus visitantes.

Última actualización:

¿Quién opera este sitio web?

Este sitio web (andrejkirbis.com) es un sitio web académico personal operado por Andrej Kirbiš, Profesor titular de la Universidad de Maribor, Facultad de Filosofía y Letras, Departamento de Sociología, Eslovenia. Es un sitio estático alojado en GitHub Pages y no tiene una base de datos del lado del servidor ni cuentas de usuario.

¿Qué datos se recopilan?

Este sitio web no utiliza herramientas de análisis de forma predeterminada. Si acepta las cookies de análisis cuando se le solicite, se carga Google Analytics 4 y se recopilan los datos estadísticos agregados descritos a continuación. Si rechaza o ignora la solicitud, no se recopilan ni envían datos de análisis.

Las páginas de GitHub (operadas por GitHub, Inc.) pueden recopilar datos básicos de registro del servidor (direcciones IP, agente de usuario del navegador, referencia y marcas de tiempo de solicitud) como parte de las operaciones normales de alojamiento. Por favor consulte el Declaración de privacidad de GitHub para más detalles.

Google Analytics 4 (opcional, basado en consentimiento)

Si acepta cookies analíticas, este sitio web carga Google Analytics 4 (ID de medición: G-GXLELRGY99). GA4 podrá entonces recopilar:

  • Vistas de páginas y rutas de navegación en este sitio web
  • País o región aproximada (no ubicación precisa)
  • Tipo de dispositivo, navegador y sistema operativo
  • La referencia o fuente que lo trajo a este sitio web

Estos datos son procesados por Google de acuerdo con Política de privacidad de Google. Se utilizan exclusivamente para comprender cómo los visitantes usan este sitio web y mejorar su contenido. Estos datos no se utilizan para publicidad ni remarketing. Todas las señales de consentimiento relacionadas con la publicidad permanecen denegadas, independientemente de su elección sobre el análisis.

Enlaces de terceros

Este sitio web enlaza a servicios externos, incluidos ORCID, Google Scholar, Scopus, Web of Science, ResearchGate, SICRIS, SciProfiles y la Universidad de Maribor. Si se aceptan cookies analíticas, los datos también se envían a Google (Google Analytics 4). Estos servicios se rigen por sus respectivas políticas de privacidad. Este sitio web no tiene control ni asume ninguna responsabilidad por el contenido o las prácticas de privacidad de esos sitios.

Configuración de cookies y consentimiento

Cuando visita este sitio web por primera vez, un banner le pregunta si acepta las cookies analíticas. Su elección se almacena en el almacenamiento local de su navegador bajo la clave ak_analytics_consent. Puede cambiar o retirar su consentimiento en cualquier momento haciendo clic Configuración de cookies en el pie de página de cualquier página.

Retirar el consentimiento significa que Google Analytics no se cargará en futuras visitas. No afecta a los datos ya recopilados por Google durante sesiones anteriores cuando se otorgó el consentimiento.

Google Fonts

Este sitio web carga fuentes de Google Fonts a través de elementos de enlace HTML. Cuando su navegador carga la hoja de estilo, se realiza una solicitud a los servidores de Google, que pueden registrar su dirección IP de acuerdo con Política de privacidad de Google. Si lo prefiere, puede bloquear estas solicitudes utilizando una extensión del navegador o un navegador centrado en la privacidad.

Contacto por correo electrónico

Si envía un correo electrónico a la dirección que figura en la página de Contacto, su dirección de correo electrónico y el contenido de su mensaje se utilizarán únicamente para responder a su consulta. Los correos electrónicos no se comparten con terceros y se eliminan cuando ya no son necesarios.

Tus derechos (GDPR)

Si aceptó cookies analíticas, Google Analytics puede contener datos agregados sobre sus visitas. Puede optar por no participar en Google Analytics a través del Complemento de inhabilitación para navegadores de Google Analytics, o retirar su consentimiento en cualquier momento mediante el enlace Configuración de cookies del pie de página.

Para obtener datos en poder de GitHub como proveedor de alojamiento, comuníquese con GitHub directamente. Para cualquier otra consulta sobre privacidad, comuníquese con: andrej.kirbis@um.si.

Cambios a esta política

Esta política de privacidad puede actualizarse periódicamente. La fecha en la parte superior de esta página refleja la revisión más reciente.
