Politique de confidentialité

Comment ce site Web traite les informations sur ses visiteurs.

Dernière mise à jour :

Qui exploite ce site Web ?

Ce site Web (andrejkirbis.com) est un site Web académique personnel exploité par Andrej Kirbiš, professeur titulaire à l'Université de Maribor, Faculté des Arts, Département de Sociologie, Slovénie. Il s'agit d'un site statique hébergé sur les pages GitHub et n'a pas de base de données côté serveur ni de comptes d'utilisateurs.

Quelles données sont collectées ?

Ce site web n’utilise pas d’outils d’analyse par défaut. Si vous acceptez les cookies d’analyse lorsque cela vous est proposé, Google Analytics 4 est chargé et recueille les données statistiques agrégées décrites ci-dessous. Si vous refusez ou ignorez la demande, aucune donnée d’analyse n’est recueillie ni envoyée.

Les pages GitHub (exploitées par GitHub, Inc.) peuvent collecter des données de base du journal du serveur (adresses IP, agent utilisateur du navigateur, référent et horodatage des demandes) dans le cadre des opérations d'hébergement normales. Veuillez vous référer au Déclaration de confidentialité de GitHub pour plus de détails.

Google Analytics 4 (facultatif, basé sur le consentement)

Si vous acceptez les cookies d'analyse, ce site Web charge Google Analytics 4 (ID de mesure : G-GXLELRGY99). GA4 pourra alors collecter :

  • Pages vues et chemins de navigation sur ce site Web
  • Pays ou région approximatif (pas de localisation précise)
  • Type d'appareil, navigateur et système d'exploitation
  • Le référent ou la source qui vous a amené à ce site Web

Ces données sont traitées par Google conformément à Politique de confidentialité de Google. Elles servent uniquement à comprendre l’utilisation du site et à améliorer son contenu. Ces données ne sont pas utilisées à des fins publicitaires ou de remarketing. Tous les signaux de consentement publicitaire restent refusés, quel que soit votre choix concernant l’analyse.

Liens tiers

Ce site Web renvoie à des services externes, notamment ORCID, Google Scholar, Scopus, Web of Science, ResearchGate, SICRIS, SciProfiles et l'Université de Maribor. Si les cookies analytiques sont acceptés, les données sont également envoyées à Google (Google Analytics 4). Ces services sont régis par leurs politiques de confidentialité respectives. Ce site Web n'a aucun contrôle et n'assume aucune responsabilité quant au contenu ou aux pratiques de confidentialité de ces sites.

Paramètres des cookies et consentement

Lorsque vous visitez ce site Web pour la première fois, une bannière vous demande si vous acceptez les cookies d'analyse. Votre choix est stocké dans la mémoire locale de votre navigateur sous la clé ak_analytics_consent. Vous pouvez modifier ou retirer votre consentement à tout moment en cliquant sur Paramètres des cookies dans le pied de page de n'importe quelle page.

Le retrait du consentement signifie que Google Analytics ne sera pas chargé lors de vos prochaines visites. Cela n'affecte pas les données déjà collectées par Google lors des sessions précédentes au cours desquelles le consentement a été accordé.

Google Fonts

Ce site Web charge les polices de Google Fonts via des éléments de lien HTML. Lorsque votre navigateur charge la feuille de style, une requête est adressée aux serveurs de Google, qui peuvent enregistrer votre adresse IP conformément à Politique de confidentialité de Google. Si vous préférez, vous pouvez bloquer ces demandes à l'aide d'une extension de navigateur ou d'un navigateur axé sur la confidentialité.

Contact par e-mail

Si vous envoyez un e-mail à l'adresse indiquée sur la page Contact, votre adresse e-mail et le contenu de votre message seront utilisés uniquement pour répondre à votre demande. Les e-mails ne sont pas partagés avec des tiers et sont supprimés lorsqu'ils ne sont plus nécessaires.

Vos droits (RGPD)

Si vous avez accepté les cookies d'analyse, Google Analytics peut détenir des données agrégées sur vos visites. Vous pouvez vous désinscrire de Google Analytics via le Module complémentaire de navigateur de désactivation de Google Analytics, ou retirer votre consentement à tout moment via le lien Paramètres des cookies dans le pied de page.

Pour les données détenues par GitHub en tant que fournisseur d'hébergement, veuillez contacter directement GitHub. Pour toute autre demande concernant la confidentialité, contactez : andrej.kirbis@um.si.

Modifications apportées à cette politique

Cette politique de confidentialité peut être mise à jour périodiquement. La date en haut de cette page reflète la révision la plus récente.
